配置说明

前往 小米 MiMo 开放平台 创建 API Key，填到上方并保存。MiMo 语音合成目前限时免费，实际计费以平台为准。

朗读按 300–400 字分块合成（块尾对齐句末），音频缓存在 data/tts/，重复朗读同一段不会重复调用接口。修改模型或音色后，缓存会自动失效。

部署在防火墙后时，服务器需要能访问 api.xiaomimimo.com（或你填写的接口地址）。
